# v1.5 Investment Feature Proposal & Product Roadmap

## Executive Summary

To elevate SplitUp from a pure expense-and-budget tracker into a comprehensive personal finance manager, we propose introducing **Investment Tracking**.

Crucially, **Investments will be tracked and displayed completely independently of Income and Expenses**:
- **Income**: Money earned (salary, freelance, side hustle, dividends).
- **Expenses**: Money spent on consumption and liabilities (groceries, rent, utilities, entertainment).
- **Investments**: Money allocated toward wealth building and assets (stocks, mutual funds, crypto, real estate, provident fund, fixed deposits) — **never mixed with income or counted as burn expenses**.

---

## 1. Technical Architecture & Database Design

### A. Room Database (`AppDatabase.kt`)
Create a new `InvestmentEntity` table alongside `ExpenseEntity` and `IncomeEntity`:

```kotlin
@Entity(tableName = "investments")
data class InvestmentEntity(
    @PrimaryKey
    val id: String = java.util.UUID.randomUUID().toString(),
    val title: String = "",
    val amount: Double = 0.0,
    val category: String = "", // e.g., Stocks, Mutual Funds, Crypto, Real Estate, Gold, Bonds
    val date: String = "",
    val description: String = "",
    val brokerOrPlatform: String = "", // e.g., Robinhood, Fidelity, Binance
    val currency: String = Currencies.EUR,
    val updatedAt: Long = System.currentTimeMillis(),
    val isDirty: Boolean = true
)
```

### B. Repository & Cloud Sync (`FinanceRepository.kt` & `CloudSyncManager.kt`)
- Add reactive Flow streams `getAllInvestments()` in `FinanceDao` and `FinanceRepository`.
- Add Firestore synchronization under `users/{uid}/investments` collection in `CloudSyncManager` to support multi-device offline-first sync.

## 2. UI & UX Design

### A. Entry Form (`AddInvestmentScreen` or 3-Way Toggle)
- Expand transaction entry with a 3-way segmented control: **Expense** | **Income** | **Investment**.
- Investment-specific fields:
  - **Asset Title** (e.g., "Apple Stock", "S&P 500 Index Fund")
  - **Amount** & Currency selector
  - **Category / Asset Class** (Stocks, Mutual Funds, Crypto, Real Estate, Gold, Bonds, etc.)
  - **Platform / Broker** (where the asset is held)
  - **Date & Notes**

### B. Dashboard & Summary Cards
- **3-Pillar Financial Summary Card**:
  - **Total Income** (Green)
  - **Total Expenses** (Red / Orange)
  - **Total Investments** (Blue / Purple - *wealth accumulation*)
- Net Cash Flow calculation: `Net Savings = Income - Expenses` (Investments are shown as asset deployment, not burned cash).

### C. Personal Transactions & Insights
- Filter chips in `PersonalExpensesScreen`: **All**, **Income**, **Expense**, **Investment**.
- Dedicated Investment Portfolio Breakdown card in `InsightsScreen` showing asset allocation percentages.
