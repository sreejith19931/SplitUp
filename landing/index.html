What's New in v1.2.0

v1.2.0 — Feature & UI Refresh
Latest Release
  • 📦
    Settled Group Archiving: Fully settled groups can now be archived using the new explicit Archive option and managed under the new "Archived" tab in Groups.
  • 🌑
    Full-Screen Dashboard Dimming: Opening the quick action menu (+) now dims the entire screen smoothly for enhanced focus.
  • ✨
    UI Hygiene & Neutrality: Removed check mark symbols across non-checkbox pages and neutralized settings sub-page backgrounds to prevent any unwanted color tints.
  • 🛡️
    Refined Danger Zone: Cleaned up Danger Zone button borders and enhanced confirmation safety dialogs.
